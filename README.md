# 公關週報工作台

把媒體監測得到的新聞，串成「篩選選題 → 整理摘要 → 產出週報 → 人工確認」的單一工作流程。

## 使用方式

1. 開啟 `dist/index.html`，或用任一靜態網站服務開啟。
2. 從媒體監測網複製新聞後，使用「貼入新聞」匯入；也可匯入 JSON、CSV 或文字檔。
3. 在收件匣勾選新聞、設定重要度，並選擇它要進入的「IR訊息／產業訊息」與【類別】。
4. 將「週報內文」寫成事實句（主體、動作、關鍵數字或背景）；需要時在「補充資訊／編輯註記」填入使用流程、限制或備註。
5. 在右側檢查週報版型預覽與可編輯文字，再複製文字輸出；不會產生 Word 檔。
6. 儲存本週紀錄；資料會保存在這台裝置的瀏覽器中。

### 貼入格式

每列一則新聞，欄位以直線 `|` 分隔：

```text
標題 | 媒體 | 2026-09-29 | https://example.com/article | 主題 | 週報內文
```

CSV 可使用相同欄位順序；JSON 可為新聞物件陣列，欄位支援 `title`、`source`、`date`、`url`、`topic`、`excerpt`、`summary`、`reportGroup`。

產出的文字週報採既有 `Soft-World PR & IR Department STATUS REPORT 工作進度報告` 格式：`Date`、`IR訊息`、`產業訊息`，以及【遊戲產業】、【金融科技產業】、【市場新遊動態】、【遊戲產業動態】、【金融科技產業動態】、【穩定幣相關新聞】等分類。原文連結保留於收件匣，複製出的週報文字不加入網址。

> 第一版採瀏覽器本機儲存。監測網沒有已驗證的跨站匯入介面時，貼入／匯入可保留人工選題與來源查核流程。
