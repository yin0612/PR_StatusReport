# 公關週報工作台

把媒體監測得到的新聞，串成「篩選選題 → 整理摘要 → 產出週報 → 人工確認」的單一工作流程。

## 使用方式

1. 開啟 `dist/index.html`，或用任一靜態網站服務開啟。
2. 從媒體監測網複製新聞後，使用「貼入新聞」匯入；也可匯入 JSON、CSV 或文字檔。
3. 在收件匣勾選新聞、設定重要度、調整順序與填寫編輯註記。
4. 在右側週報草稿檢查內容、手動修改，再複製輸出。
5. 儲存本週紀錄；資料會保存在這台裝置的瀏覽器中。

### 貼入格式

每列一則新聞，欄位以直線 `|` 分隔：

```text
標題 | 媒體 | 2026-09-29 | https://example.com/article | 主題
```

CSV 可使用相同欄位順序；JSON 可為新聞物件陣列，欄位支援 `title`、`source`、`date`、`url`、`topic`、`excerpt`、`summary`。

> 第一版採瀏覽器本機儲存。監測網沒有已驗證的跨站匯入介面時，貼入／匯入可保留人工選題與來源查核流程。
